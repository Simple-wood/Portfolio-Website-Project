# Kishal's Warudo

A personal portfolio website showcasing my education, skills, portfolio projects along with a blog system.

## Features

- **Home**: Welcome page with introduction
- **Education**: Academic background and achievements
- **Portfolio**: Showcase of projects and work
- **Skills**: Technical skills and competencies
- **Blog**: Personal blog posts and articles
- **Login System**: Secure access for blog management

## Technologies Used

- **Backend**: PHP
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Responsive design with mobile support
- **Fonts**: Google Fonts (Montserrat, Play, Quicksand, Staatliches)

## Project Structure

```
/
├── index.php              # Home page
├── education.php          # Education section
├── portfolio.php          # Portfolio showcase
├── skills.php             # Skills page
├── viewBlog.php           # Blog viewer
├── login.php              # Login page
├── addEntry.php           # Add blog entry
├── addPost.php            # Add post functionality
├── css/                   # Stylesheets
├── images/                # Image assets
└── javascript/            # Client-side scripts
```
